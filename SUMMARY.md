## 🚀 Next Steps

### 1. Test Locally (Right Now)
Open `index.html` in your browser and test:
- Click the `+` button
- Select "Neerav" as author
- Write a poem
- Save it
- Open the poem → Click "Share Snippet"
- See the code copied!

### 2. Deploy to GitHub Pages
```bash
cd "C:\Users\neera\OneDrive\Desktop\HTML learning\writing-archive"
git init
git add .
git commit -m "Initial commit: Our shared poetry archive"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/writing-archive.git
git push -u origin main
```

Then:
- Go to GitHub repo → Settings → Pages
- Source: `main` branch, `/root` folder
- Save → Wait 1-2 minutes
- Your site is live at: `https://YOUR-USERNAME.github.io/writing-archive/`

### 3. Share with Your Friend
Send her the link! She can:
- Open it on any device
- Click `+` to write
- Select "Friend" as author
- Save poems instantly
- Click "Share Snippet" to send you poems via chat

### 4. Add Her Poems to GitHub
When she sends you a snippet:
1. Go to GitHub → `data/writings.js` → Edit
2. Find line 49 (inside `WRITINGS` array)
3. After the last poem's closing `}`, add a comma
4. Paste her snippet
5. Commit → Done! Her poem is live.
